# Монтажный слой на Remotion

Накладывает мемы и эмодзи поверх готовых вертикальных роликов
(1080×1920, 30 fps, субтитры вшиты в исходник).

Правила работы — в `CLAUDE.md`.

## Команды

```bash
npm run studio           # превью, все выпуски в списке композиций
npm run new -- kafka2 ~/Downloads/0910.mp4   # новый выпуск: папка, замеры, заготовки, реестр
npm run measure -- src/features/kafka/source/0905.mp4   # замеры отдельно; SUB_Y=<px> задаёт полосу субтитров
npm run proxy -- kafka "<vf>"     # прокси с грейдом из оригинала в public/episodes/kafka/
npm run lint -- kafka             # линт раскладки (хук гонит сам после правки episode.ts)
npm run check -- out/kafka.mp4    # приёмка рендера + out/kafka.check.jpg (хук гонит сам после рендера)
npm run render:devops    # -> out/devops.mp4
npm run render:yandex    # -> out/yandex.mp4
npm run render:kafka     # -> out/kafka.mp4
npm run render:tester    # -> out/tester.mp4
npm run render:tester_new  # -> out/tester_new.mp4
npm run render:autoscaling   # -> out/autoscaling.mp4 (motion-обучалка)
```

## Структура

Проект разложен по фичам: **один выпуск — одна папка**, в ней всё, что
относится только к нему. Общее — дизайн-правила, мемы, компоненты — в `shared/`.

```
src/features/               по папке на выпуск
  index.ts                  реестр: порядок композиций в Studio, сюда добавляется новый
  devops/                   «как воспитать идеального девопса», 47.2 c
    episode.ts              раскладка: геометрия кадра, оверлеи, тайминги
    notes.md                замеры и грейд именно этого ролика
    source/0904.mp4         оригинал HEVC — не трогаем, только читаем
    script.txt              текст сценария (если есть)
    subtitles.srt           SRT из CapCut (если выгружен)
    measure/                frames.jpg, subtitles.jpg, grade.jpg от measure.sh
  yandex/                   «как воспитать идеального разработчика», 76.1 c
  kafka/                    «как масштабировать консьюмер в кафке», 74.9 c
  tester/                   «как воспитать идеального тестировщика», 57.3 c
  tester_new/               пересъёмка тестировщика, 59.1 c; субтитры кладёт автор
  autoscaling/episode.json  motion-обучалка «BACKEND ЗА 30 СЕКУНД», данные выпуска

src/shared/                 общее для всех выпусков
  config.ts                 FPS / WIDTH / HEIGHT
  fonts.ts                  Noto Color Emoji
  reel/Reel.tsx             композиция реела: видео + оверлеи по данным
  reel/types.ts             схема выпуска: Overlay, Episode
  overlays/                 MemeCard, EmojiPop, BrollClip
  cuts/                     перебивки на полный экран (Cut, Lanes, CutSpec)
  motion/                   токены и компоненты motion-системы

src/Root.tsx                собирает композиции из реестра фич
public/
  episodes/<фича>/*.mp4     прокси H.264 с впечённым грейдом — то, что играет Studio
  pictures/*.jpg            мемы, то, что реально идёт в кадр
  pictures/memes.json       опись: описание, теги, предел ширины, тип фона
  broll/                    прокси подсъёмов
scripts/                    пайплайн: new-episode, measure, proxy, lint-episode, check-render, hooks
.claude/settings.json       хуки: защита source/, замер перед раскладкой, линт, приёмка
.claude/skills/             /new-episode и /check
pictures/, footage/         сырьё от автора: мемы и подсъёмы до обработки
```

Прокси лежат в `public/`, а не в фиче, потому что `staticFile` в Remotion
читает только оттуда. Подпапка `episodes/<фича>/` держит их сгруппированными
по выпускам.

## Новый выпуск

1. Папка `src/features/<имя>/`, оригинал — в `source/`, сценарий рядом.
2. `npm run measure -- src/features/<имя>/source/<файл>.mp4` — листы лягут в
   `measure/`. Посмотреть `frames.jpg`, `subtitles.jpg`, `grade.jpg`.
3. Пережечь прокси с грейдом **из оригинала** в `public/episodes/<имя>/`:
   ```bash
   ffmpeg -i src/features/devops/source/0904.mp4 -vf "selectivecolor=reds=0.32 -0.13 0 0,colortemperature=temperature=7300:pl=1" -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k public/episodes/devops/0904_h264.mp4
   ```
   Числа подбираются заново под каждый ролик по `grade.jpg`; записать их в
   `notes.md` фичи.
4. Завести `episode.ts`, заполнить `geometry` по замерам, расставить оверлеи,
   добавить строку в `src/features/index.ts`. Добавить скрипт `render:<имя>`
   в `package.json`.
5. Отрендерить, пройти чек-лист из `CLAUDE.md`.

## Графика для обучалок

Перебивки на полный экран. Оверлей `kind: 'cut'` внутри выпуска: кадр
закрывается целиком, звук мастера идёт под ним. Цвет, кегли и характер
движения берутся из `src/shared/motion/theme.ts` — своих значений у компонентов нет.

```
src/shared/cuts/Cut.tsx              рамка перебивки: рубрика, бейдж, заголовок,
                                     схема, шкала, стикер, субтитр
src/shared/cuts/components/Lanes.tsx партиции топика: очередь, стрелка, консьюмер
src/shared/cuts/types.ts             CutSpec — перебивка описывается данными
src/shared/motion/theme.ts           токены: цвет, типографика, формы, длительности
```

Схема задаётся шагами `CutStep` — что показано и в каком кадре это изменилось
(кадры отсчитываются от начала перебивки). Пример — три перебивки в
`src/features/kafka/episode.ts`.

Посмотреть движение: `npm run studio`, композиция `Kafka`.

| голова по ширине | 300–675 | 137–725 | 250–790 | 235–830 |

Разница между выпусками — причина, по которой геометрию надо мерить каждый раз.
В `Devops` карточки пришлось загнать в правый верхний угол и ограничить 420 px;
в `Yandex` они вдвое крупнее и чередуются лево/право.

**Для съёмки:** если нужны крупные мемы — оставляй над головой 400–500 px запаса.

## Цветокоррекция

Съёмка на закате даёт сильный тёплый сдвиг: V держалась на 151 при нейтрали 128.
Лечится двумя фильтрами — `selectivecolor` гасит красный точечно (общий
`colorbalance` уводил стену в серо-зелёный), мягкий `colortemperature` добавляет
нейтральности. `reds=0.45` уже пережим, кожа становится оливковой; рабочее 0.32.

Грейд впечён в прокси, поэтому превью в Studio совпадает с рендером.

Заваленность была постоянной по всему ролику, не плавающей, — поэтому хватило
одного грейда. Если дубли сняты с разбросом по времени, проверять дрейф
в выводе `measure.sh` и корректировать посегментно.

Числа переносить между роликами нельзя: в `Tester` (0905-1) завал вдвое слабее
— V держалась на 141 против 151, — и `reds=0.32` уже уводил кожу в оливковый.
Рабочее там `reds=0.20` с мягким `colortemperature=6900`. Ориентир: поправка
пропорциональна отрыву V от 128.
