# Handoff: motion-система «BACKEND ЗА 30 СЕКУНД»

Пакет для передачи в Codex / Claude Code, чтобы агент генерировал выпуски
Remotion по правилам системы, а не по своему вкусу.

## Что здесь

| Файл | Что это |
|------|---------|
| `AGENTS.md` | Свод правил для агента. Главный файл пакета. |
| `theme.ts` | Токены: цвет, типографика, формы, длительности в кадрах, кривые, биты. |
| `types.ts` | Схема данных выпуска. |
| `example-episode.json` | Готовый выпуск «Автоскейлинг» как эталон данных. |
| `reference/motion-system-v2.dc.html` | Живой прототип: анимированный выпуск и все компоненты. Открывается в браузере. |
| `reference/motion-system-v1.dc.html` | Первая версия, для истории. |
| `reference/frame-autoscaling.png` | Исходный кадр, с которого система началась. |

## Как подключить

1. Скопируйте `AGENTS.md` в корень репозитория Remotion-проекта.
   Для Claude Code продублируйте его как `CLAUDE.md` — оба инструмента читают
   свой файл автоматически при каждом запросе.
2. Положите `theme.ts` и `types.ts` в `src/` проекта.
3. Положите `example-episode.json` в `src/episodes/`.
4. В `AGENTS.md` / `CLAUDE.md` добавьте наверх одну строку с путями, если
   структура проекта отличается от `src/`:

   ```
   Токены: src/theme.ts. Схема выпуска: src/types.ts. Эталон: src/episodes/autoscaling.json.
   ```

## Первая задача агенту

Формулировка, с которой стоит начать:

> Прочитай AGENTS.md, theme.ts и types.ts. Собери композицию `Episode`
> 1080×1920, 30 fps, 900 кадров: четыре бита из раздела 6, компоненты из
> раздела 7, данные читаются из episodes/autoscaling.json. Все значения бери
> из theme.ts, литералов в компонентах быть не должно. Дрейф камеры и зона
> субтитров — на уровне обёртки выпуска. Начни с компонентов Meter и SlotRow:
> метр ведёт, слоты догоняют с lag.

Дальше — по одному компоненту за раз. Разом всё писать не стоит: система живёт
в деталях тайминга, и их проще проверять по одному.

## Как проверять результат

Чек-лист, по которому отличается «сделано по системе» от «похоже на систему»:

- [ ] В коде нет цветовых литералов, кроме `theme.ts`.
- [ ] Все длительности — из `dur`, все кривые — из `ease` / `popSpring`.
- [ ] Ни одно число не появляется на экране готовым.
- [ ] Метр стартует раньше слотов на `dur.lag`.
- [ ] Перед битом `event` есть пауза `dur.hold`, в которой не двигается ничего.
- [ ] `alarm` встречается только в бите `hook` и нигде не пересекается с `accent`.
- [ ] Нижние 16 % кадра заняты субтитрами, схема туда не заезжает.
- [ ] Компоненты считают время от нуля своей `Sequence`, без арифметики
      по абсолютным кадрам.
- [ ] Последний кадр композиционно совпадает с первым.

## О файлах-прототипах

`reference/*.dc.html` — это **дизайн-референсы**, а не код для переноса.
Анимации в них сделаны CSS-кейфреймами, чтобы правила системы можно было
увидеть в браузере. В Remotion всё это пересобирается заново: те же значения,
но через `useCurrentFrame`, `interpolate` и `spring`. Не копируйте оттуда
разметку и не пытайтесь конвертировать кейфреймы — берите числа.

## Фиделити

Высокое. Цвета, размеры кегля, радиусы, тени, тайминги и кривые — финальные.
Открытыми остаются: интро/аутро-брендинг, звуковые акценты и компонент схемы
«запрос → сервис → БД».
