04

Движение

Три кривые, четыре длительности, 30 fps
Выход
cubic-bezier(.16,1,.3,1)
Появление текста, рост полос, вытягивание линий. Основная кривая системы.
Перелёт
spring · damping 12 · stiffness 180
Стикеры, бейджи, включение слотов. Всё, что должно «щёлкнуть».
Проезд
cubic-bezier(.45,.05,.55,.95)
Курсор, панорама по интерфейсу, смена сцен. Начинается и кончается спокойно.
6f
Микро: бейдж, клик, подсветка
10f
Элемент: строка, слот, стикер
18f
Блок: заголовок целиком, схема
24f

→Правило: одновременно двигается один смысловой объект. Каскад внутри блока — шаг 3–4 кадра, не больше пяти элементов подряд, иначе зритель ждёт вместо того, чтобы читать.

06

Перенос в Remotion

Что становится кодом
// theme.ts
paper: '#F1EDE3'
ink: '#16130F'
accent: '#DFA94C'
muted: '#9A9287'
// dur (frames @30fps)
micro: 6 · elem: 10 · block: 18 · scene: 24
stagger: 3
// easing
out: Easing.bezier(.16,1,.3,1)
travel: Easing.bezier(.45,.05,.55,.95)
pop: spring({ damping: 12, stiffness: 180 })
Один компонент на элемент кадра
TitleBlock, SlotRow, Meter, Sticker, Spotlight, Counter, Outro. Внутри каждого — только своё движение, композиция их не переопределяет.
Время задаёт Sequence, не компонент
Компонент анимируется от нулевого кадра своей последовательности. Сдвиги — только через from, тогда перемонтаж выпуска не ломает анимации.
Текст выпуска — данные
Заголовок, лид, число слотов, проценты, стикеры лежат в JSON выпуска. Новый выпуск — новый файл данных, не новый код.
