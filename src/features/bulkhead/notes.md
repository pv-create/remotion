# Bulkhead — «паттерн Bulkhead: пул потоков на каждый ресурс», 63.9 c

Оригинал `source/0910.mp4`, прокси `public/episodes/bulkhead/0910_hook_h264.mp4`.

## Хук из Kafka

В начале — 41 кадр (1.367 с) девушки «она 10/10 но…» из оригинала Kafka
(`src/features/kafka/source/0905.mp4`, кадры 0–40; на 41–42 там уже вылезает
субтитр «но» из того выпуска). Склеено в прокси вместе с оригиналом bulkhead
и его грейдом, звук хука поднят на 4 dB (в Kafka он был на 4 dB тише речи,
здесь речь громче). Первый прокси без хука — `0910_h264.mp4`, оставлен.

Все тайминги в `episode.ts` — по карте оригинала плюс `HOOK = 41 / 30`;
листы в `measure/` сняты без хука, к ним прибавлять 1.367 с.

```bash
ffmpeg -i <kafka-оригинал> -i <bulkhead-оригинал> -filter_complex "
  [0:v]trim=end_frame=41,setpts=PTS-STARTPTS[hv];
  [0:a]atrim=end=1.3667,asetpts=PTS-STARTPTS,volume=4dB[ha];
  [1:v]selectivecolor=reds=0.20 -0.08 0 0,setpts=PTS-STARTPTS[bv];
  [1:a]asetpts=PTS-STARTPTS[ba];
  [hv][ha][bv][ba]concat=n=2:v=1:a=1[v][a]" -map "[v]" -map "[a]" -r 30 \
  -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p -c:a aac -b:a 192k \
  -movflags +faststart public/episodes/bulkhead/0910_hook_h264.mp4
```

## Перебивки

Схема «пулы потоков» — `src/shared/cuts/components/Pools.tsx`, написана под
этот выпуск: рамка = вызывающий сервис, строка = пул (слоты → стрелка →
ресурс). Застрявший поток — `alarm` в проблеме и `ink` в решении (alarm и
accent в одном кадре не встречаются), рабочий — `accent`.

| 0 | 6.4–13.5 | сетап: рамка поиска, на «сервис рекомендаций» встаёт ресурс, на «ходит в рекомендации» поток уходит туда, на «перестают отвечать» время ответа в потолок, поток застревает, стикер «не отвечают» |
