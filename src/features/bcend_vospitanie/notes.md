# BcendVospitanie — «как воспитать идеального бэкендера», 36.5 c

Оригинал `source/0910.mp4`, прокси `public/episodes/bcend_vospitanie/0910_h264.mp4`.

## Геометрия

Замер по `measure/frames.jpg` и полным кадрам на 1, 10, 20, 30 c. Крупность
как в tester_new, полоса субтитров 1440–1600 (карта снята с SUB_Y=1420).

| волосы сверху | глаза | подбородок | субтитры сверху | голова по ширине | свободно над головой |
|---|---|---|---|---|---|
| 300 | 690 (брови 640) | 1040 | 1440 | 280–810 | ~300 px |


## Грейд

`selectivecolor=reds=0.20 -0.08 0 0`

```bash
./scripts/proxy.sh bcend_vospitanie "selectivecolor=reds=0.20 -0.08 0 0"
```

## Пословная карта

Снята с вшитых субтитров по четверти секунды (`select` по кадрам 0 и 7 из
каждых 15). Пункты: «1-ое» 3.0, «2-ое» 14.25, «3-ье» 22.0, «подписывайся»
34.5. `script.txt` автора — только текст, таймингов там нет.

## SFX

`click.mp3` на трёх счётчиках, volume 0.5. 0️⃣ на «самооценка на нуле» автор
убрал, щелчок ушёл вместе с ним. На остальных
акцентах звука нет: щелчок без картинки читается как брак дорожки.
