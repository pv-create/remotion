## Ускорение вступления

По просьбе автора («в начале тухло»): до «Король ночи» (0–6.5 с оригинала)
видео и звук ускорены в 1.2 раза (`setpts=PTS/1.2`, `atempo=1.2`), дальше
1:1. Стык на 6.5 с попадает в паузу перед «король» (6.50–6.65 тишина).
Первая шутка теперь на 5.4 с вместо 6.7. Всё, что после стыка, в раскладке
сдвинуто на −1.08 с; тайминги в пословной карте выше — по оригиналу.

```bash
ffmpeg -y -i src/features/got2/source/0922.mp4 -filter_complex "
[0:v]trim=end=6.5,setpts=PTS/1.2[v0];[0:v]trim=start=6.5,setpts=PTS-STARTPTS[v1];
[0:a]atrim=end=6.5,asetpts=PTS-STARTPTS,atempo=1.2[a0];[0:a]atrim=start=6.5,asetpts=PTS-STARTPTS[a1];
[v0][a0][v1][a1]concat=n=2:v=1:a=1[vc][ac];
[vc]fps=30,selectivecolor=reds=0.15 -0.06 0 0,colortemperature=temperature=6800:pl=1[v]" \
  -map "[v]" -map "[ac]" -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p \
  -c:a aac -b:a 192k -movflags +faststart public/episodes/got2/0922_intro12_h264.mp4
```

Монтаж во вступлении: 🐉 на «Игры престолов», 💻 на «в IT», ✌️ на «Вторая
часть», а на «Первая часть уже в профиле, смотри по ссылке» — полоса из
четырёх карточек первой части (Джон и Дейнерис, Рамси, Нед, Джоффри) по 230 px
в ряд, влетают по очереди с шагом 0.3 с и уходят вместе на 5.4 с, когда
приходит Король ночи.

## Ускорение основной части

Вторая просьба автора после просмотра: вступление оставить на 1.2x, а всё
после стыка ускорить в 1.1x. Прокси `0922_intro12_body11_h264.mp4`, ~50.0 с:

```bash
ffmpeg -y -i src/features/got2/source/0922.mp4 -filter_complex "
[0:v]trim=end=6.5,setpts=PTS/1.2[v0];[0:v]trim=start=6.5,setpts=(PTS-STARTPTS)/1.1[v1];
[0:a]atrim=end=6.5,asetpts=PTS-STARTPTS,atempo=1.2[a0];[0:a]atrim=start=6.5,asetpts=PTS-STARTPTS,atempo=1.1[a1];
[v0][a0][v1][a1]concat=n=2:v=1:a=1[vc][ac];
[vc]fps=30,selectivecolor=reds=0.15 -0.06 0 0,colortemperature=temperature=6800:pl=1[v]" \
  -map "[v]" -map "[ac]" -c:v libx264 -crf 18 -preset slow -pix_fmt yuv420p \
  -c:a aac -b:a 192k -movflags +faststart public/episodes/got2/0922_intro12_body11_h264.mp4
```

Пересчёт таймингов: для оригинального t ≥ 6.5 новое время
`5.4167 + (t − 6.5) / 1.1`. Визуальные оверлеи сжаты и по from, и по to;
у SFX сдвинут только from, длина окна сохранена — иначе хвост `impact-sub`
(3.65 с) обрезался бы. Клик на «Король ночи» по-прежнему в паузе перед
словом: тишина 5.42–5.55, «король» с 5.60.
