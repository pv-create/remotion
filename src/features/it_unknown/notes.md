# ItUnknown — «Три вещи в айти, которые невозможно объяснить», 46.2 c

в `source/` скопирован под чистым именем), прокси
`public/episodes/it_unknown/0929_h264.mp4`, 1:1 без ускорения.

скрам-мастеру». Ошибки во вшитых субтитрах: «войти» вместо «в айти» (0.8 и
40.8 с), «делики» (11.7, 35.2), «затач» (15.2), «ненорма» (13.3).

(14.1), `car` на «час на дорогу» (30.6).
